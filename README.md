🎓 Student Registration Form

A simple and responsive Student Registration Form created using HTML, CSS, and JavaScript. This project allows students to enter their details and provides real-time form validation.

🚀 Features

- Student name input
- Email address validation
- Password validation (minimum 6 characters)
- Bio field with a 200-character limit
- Live character counter
- Real-time error messages
- Submit button enabled only when all fields are valid
- Success message after registration
- Simple and user-friendly design
- Responsive layout

🛠️ Technologies Used

- HTML5 – Structure of the registration form
- CSS3 – Styling and responsive design
- JavaScript – Form validation and DOM manipulation

💻 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open "index.html" in your browser.
4. Enter the student details.
5. Test the form validation and submit the form.
